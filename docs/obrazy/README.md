# Obrazy w dokumentacji

## Zrzuty strony zbiórki

README odwołuje się do dwóch plików w tym katalogu:

| Plik | Co przedstawia |
|---|---|
| `zbiorka-schronisko-pl.png` | profil schroniska na ratujemyzwierzaki.pl, wersja polska |
| `zbiorka-schronisko-en.png` | ta sama strona przetłumaczona na angielski |

⚠️ **Zrzuty przedstawiają stronę osoby trzeciej.** Zbiórkę prowadzi TOZ
Schronisko dla Bezdomnych Zwierząt we Wrocławiu — nie my. Zrzuty służą
wyłącznie temu, żeby czytelnik wiedział, dokąd prowadzi odnośnik, zanim
w niego kliknie.

⚠️ **Kwoty na zrzutach są migawką i szybko się dezaktualizują.** Dlatego
w README stoi przy nich data sprawdzenia, a obok żywy odnośnik. Nigdy nie
opisujemy stanu zbiórki na podstawie obrazka.
