# Images in the documentation

## Screenshots of the fundraiser page

The main README refers to two files in this directory:

| File | What it shows |
|---|---|
| `zbiorka-schronisko-pl.png` | the shelter's profile on ratujemyzwierzaki.pl, Polish version |
| `zbiorka-schronisko-en.png` | the same page translated into English |

**The screenshots show a third party's page.** The fundraiser is run by TOZ Schronisko dla Bezdomnych Zwierząt we Wrocławiu, not by us. They exist only so the reader knows where the link leads before clicking it.

**The amounts in the screenshots are a snapshot and go out of date quickly.** That is why the README states the date they were checked and puts a live link beside them. We never describe the state of the fundraiser from an image.

Source: https://www.ratujemyzwierzaki.pl/schroniskowroclaw
